## 🧮 Progressive Curriculum Modules

1. **Pure Functions (`1 - Funciones`):** Function declaration patterns and scope isolation.
2. **Deterministic Returns (`2 - Return`):** Arithmetic result piping and functional chaining.
3. **Parameterized Computation (`3 - Parámetros`):** Dynamic argument handling and input validation.
4. **Fuel Computation Engine (`4 - Calcular Combustible`):** Distance-to-consumption ratio estimation interface.
5. **Standard Math Operations (`5 - Math`):** Trigonometric, rounding, and square root operations.
6. **Stochastic Sampling (`6 - Random`):** Bounded random integer generation and pseudo-random mechanics.
7. **Production Calculator App (`7 - Calculadora`):** Full-featured interactive desktop calculator interface with key listeners.
